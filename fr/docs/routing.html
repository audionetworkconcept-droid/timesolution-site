Routing

Mode Standalone Windows

FeedZero s'insère directement dans la chaîne audio via les drivers ASIO ou WDM de votre interface. Aucun DAW requis.

Interface audio
→
Driver ASIO/WDM
→
FeedZero
→
Enceintes / Wedges

Latence typique : dépend du buffer ASIO (typiquement 2–8 ms à 256 samples / 48 kHz).

Mode Insert Dante

FeedZero s'insère comme un device Dante standard sur le réseau. Aucune modification d'infrastructure nécessaire.

Dante Rx 1-2
→
FeedZero
→
Dante Tx 1-2

Aucune modification du réseau Dante nécessaire. Compatible avec tout périphérique Dante standard.

Mode Plugin DAW

Insérez FeedZero sur une piste ou un bus dans votre DAW.

  • VST3 — Reaper, Nuendo, Studio One, Cubase
  • AAX — Pro Tools 2023+

Latence : nulle (mode zero-latency si disponible dans votre DAW).

Channel Mode

Stereo → Stereo

Détection du larsen sur le MID = (L+R)/2. Les mêmes notches appliqués sur L et R. Pour retours stéréo.

Mono → Stereo

Entrée mono, sortie stéréo. Utile pour certaines configurations de monitoring avec double wedge ou in-ears.

Mono → Mono

Le plus simple. Une entrée, une sortie. Pour wedges mono classiques. Recommandé pour débuter.

💡

Pour une latence minimale en standalone, utilisez un driver ASIO avec un buffer de 64 ou 128 samples.
