Prise en main

Installation

💡

Téléchargez l'installeur depuis la page Télécharger.

  1. Téléchargez l'installeur depuis /fr/download
  2. Lancez l'installeur en tant qu'administrateur (clic droit → Exécuter en tant qu'administrateur)
  3. Suivez les étapes de l'assistant
  4. Entrez votre clé de licence au premier lancement

Premier lancement

  1. Sélectionnez votre interface audio dans les préférences
  2. Choisissez le routing (Standalone / Dante / Plugin)
  3. Définissez le mode de canal (Stereo→Stereo, Mono→Stereo, Mono→Mono)
  4. Cliquez sur Démarrer le traitement

Activation

  • La licence est vérifiée au lancement.
  • Connexion internet requise pour la première activation.
  • Activation hors-ligne disponible sur demande : contact@audiosn.com
⚠️

Conservez votre clé de licence en lieu sûr. Ne la partagez pas.

Premiers tests

  • Démarrez en mode Stage Lock.
  • Testez le gain before feedback avec votre rig normal.
  • Lancez Auto-Setup pour un profil de départ adapté à votre rig.
  • Ajustez les paramètres selon vos retours terrain.
💡

Testez toujours avant un événement réel. Les conditions acoustiques varient.
