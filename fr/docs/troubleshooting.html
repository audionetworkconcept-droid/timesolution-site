Dépannage

FeedZero ne détecte pas mon interface audio

  • Vérifiez que le driver ASIO est installé et à jour
  • En mode WDM, certaines interfaces nécessitent un redémarrage
  • Consultez les logs de session (Menu → Logs)
  • Essayez de relancer FeedZero en administrateur

Le larsen continue malgré FeedZero

  • Vérifiez le routing — FeedZero est-il bien dans la chaîne de signal ?
  • Augmentez la Sensitivity
  • Passez en mode KILL si urgent
  • Le gain before feedback est-il trop élevé ?
💡

Si le larsen persiste en mode KILL, le problème est peut-être en amont du routing FeedZero.

FeedZero introduit de la latence perceptible

  • Réduisez le buffer ASIO (64 ou 128 samples)
  • En mode Plugin DAW, activez le mode zero-latency
  • En mode Dante, vérifiez la configuration réseau

Ma licence n'est pas reconnue

  • Vérifiez votre connexion internet (première activation)
  • Vérifiez que vous utilisez la bonne clé
  • Contactez contact@audiosn.com avec votre clé de licence
💡

Activation hors-ligne disponible sur demande.

Bruit ou artefacts après activation d'un notch

  • Réduisez Suppression Strength
  • Réduisez Max Notches
  • Relancez Auto-Setup pour recalibrer
  • Passez à un Notch Width plus étroit (Q élevé)

Bouton PANIC ne répond pas

⛔

Ne devrait jamais arriver. Si c'est le cas, contactez le support immédiatement : contact@audiosn.com
