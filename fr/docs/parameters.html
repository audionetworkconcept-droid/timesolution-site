Paramètres

Référence complète des paramètres de FeedZero. Tous les paramètres sont accessibles depuis l'interface principale.

Paramètre Plage Par défaut Description
Suppression Strength 0–100% 60% Profondeur des notches. 100% = protection max mais impact sonore potentiel. 50–70% recommandé en Stage Lock.
Sensitivity 0–100% 50% Seuil de déclenchement de la détection. Trop haut = larsen avant action. Trop bas = faux positifs.
Max Notches 1–24 8 Nombre maximum de notches actifs simultanément. 6–12 recommandé selon la salle.
Notch Width Narrow–Wide (Q 1–30) Medium Narrow (Q élevé) = précis. Wide = plus grossier mais plus robuste.
Channel Mode Stereo→Stereo / Mono→Stereo / Mono→Mono Auto Mode de traitement selon le routing.
Mode Stage Lock / KILL / PANIC Stage Lock Mode de suppression actif.
