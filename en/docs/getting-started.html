Getting Started

Installation

💡

Download the installer from the Download page.

  1. Download the installer from /en/download
  2. Run the installer as administrator (right-click → Run as administrator)
  3. Follow the setup wizard
  4. Enter your license key on first launch

First Launch

  1. Select your audio interface in preferences
  2. Choose routing mode (Standalone / Dante / Plugin)
  3. Set the channel mode (Stereo→Stereo, Mono→Stereo, Mono→Mono)
  4. Click Start Processing

Activation

  • License is verified at launch.
  • Internet connection required for first activation.
  • Offline activation available on request: contact@audiosn.com
⚠️

Keep your license key in a safe place. Don't share it.

First Tests

  • Start in Stage Lock mode.
  • Test the gain before feedback with your normal rig.
  • Run Auto-Setup for a starting profile adapted to your rig.
  • Adjust parameters based on real-world results.
💡

Always test before a live event. Acoustic conditions vary.
