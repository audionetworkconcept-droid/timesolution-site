Docs / Routing

Routing

Standalone Windows Mode

[Audio Interface] → [ASIO/WDM Driver] → [FeedZero] → [Speakers/Wedges]

Typical latency: depends on ASIO buffer (typically 2–8 ms at 256 samples / 48 kHz).

Dante Insert Mode

[Dante Rx 1-2] → [FeedZero] → [Dante Tx 1-2]

No Dante network modification required. Compatible with any standard Dante device.

DAW Plugin Mode

Insert FeedZero on a track or bus in your DAW.

  • VST3: Reaper, Nuendo, Studio One, Cubase
  • AAX: Pro Tools 2023+

Latency: none (zero-latency mode if available in your DAW).

Channel Mode

Stereo→Stereo (linked)

Feedback detection on MID = (L+R)/2. Same notches applied to L and R. For stereo monitors.

Mono→Stereo

Mono input, stereo output. Useful for certain monitoring configurations.

Mono→Mono

Simplest mode. One input, one output. For classic mono wedges.

💡

For minimum latency in standalone mode, use an ASIO driver with 64 or 128 sample buffer.
