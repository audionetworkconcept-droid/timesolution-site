Troubleshooting

FeedZero doesn't detect my audio interface

  • Check that the ASIO driver is installed and up to date
  • In WDM mode, some interfaces require a restart
  • Check session logs (Menu → Logs)
  • Try running FeedZero as administrator

Feedback persists despite FeedZero

  • Check routing — is FeedZero actually in the signal chain?
  • Increase Sensitivity
  • Switch to KILL mode if urgent
  • Is the gain before feedback too high?
💡

If feedback persists in KILL mode, the issue may be upstream of the FeedZero routing.

FeedZero introduces noticeable latency

  • Reduce ASIO buffer (64 or 128 samples)
  • In DAW plugin mode, enable zero-latency mode
  • In Dante mode, check network configuration

My license is not recognized

  • Check your internet connection (first activation)
  • Verify you're using the correct key
  • Contact contact@audiosn.com with your license key
💡

Offline activation available on request.

Noise or artifacts after notch activation

  • Reduce Suppression Strength
  • Reduce Max Notches
  • Re-run Auto-Setup to recalibrate
  • Switch to narrower Notch Width (higher Q)

PANIC button is unresponsive

🚫

This should never happen. If it does, contact support immediately: contact@audiosn.com
