Parameters

Complete reference for FeedZero parameters. All parameters are accessible from the main interface.

Parameter Range Default Description
Suppression Strength 0–100% 60% Notch depth. 100% = max protection but potential sonic impact. 50–70% recommended in Stage Lock.
Sensitivity 0–100% 50% Detection trigger threshold. Too high = feedback before action. Too low = false positives.
Max Notches 1–24 8 Maximum number of active notches simultaneously. 6–12 recommended depending on the room.
Notch Width Narrow–Wide (Q 1–30) Medium Narrow (high Q) = precise. Wide = coarser but more robust.
Channel Mode Stereo→Stereo / Mono→Stereo / Mono→Mono Auto Processing mode depending on routing.
Mode Stage Lock / KILL / PANIC Stage Lock Active suppression mode.
